# Before making the repository public

- [ ] Inspect screenshots for names, email addresses, tenant URLs or private organization details.
- [ ] Redact private identifiers where needed.
- [ ] Confirm all sample data is fictional or approved for public sharing.
- [ ] Check the PBIX for private source paths, credentials or confidential data.
- [ ] Confirm the report opens and data sources can be reconnected.
- [ ] Never include passwords, tokens or connection secrets.
- [ ] State clearly that data is for demonstration only.
